# Inter Font Files

This directory contains the Inter font family files bundled with the application.

## Required Files

Bundled files (from https://rsms.me/inter/):

- `Inter-Regular.ttf` (400 weight)
- `Inter-Medium.ttf` (500 weight)
- `Inter-SemiBold.ttf` (600 weight)
- `Inter-Bold.ttf` (700 weight)

## Fallback

If Inter is not available, the app will fall back to:
1. Segoe UI (Windows)
2. system-ui (macOS/Linux)
3. Default sans-serif
